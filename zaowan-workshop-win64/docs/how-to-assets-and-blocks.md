# 怎么插入背景/音乐，积木在哪里

这一页专门回答两个“功能明明做了但找不到入口”的问题；两步都在工作台顶部工具栏和游戏画面上。

## 一、插入背景 / 音乐

素材不是写在配方 JSON 里的路径，而是**上传进项目、再挂到槽位**，所以有三步：

1. 打开工程，工作台上方点 **外观素材**（游戏画面左上角也有一个 **＋ 插入背景 / 音乐** 按钮，效果一样）。
   右侧“证据与设置”面板会切到 **素材** 页签。
2. 在 **＋ 上传图片或音频** 的虚线框里点一下选文件（也可以把文件直接拖进去）。
   - 图片：PNG / JPEG / WebP，≤4 MiB（服务端会用 sharp 重新编码并清除元信息）
   - 音频：MP3 / OGG / WAV，≤12 MiB（会校验文件头）
3. 上传完成后，该素材卡片上会出现按钮：
   - 图片 → **设为背景**
   - 音频 → **设为音乐**

此时页面顶部会出现“未保存修改”的提示，回到工具栏点 **保存为新版本**，游戏画面立刻换背景、循环播放音乐。
面板顶部的“当前背景 / 当前音乐”会显示挂的是哪个文件，点 **取消** 可以解绑。

### 它到底改了什么

挂槽位写入的是配方的 `presentation.assets`，形如：

```json
{ "presentation": { "assets": [{ "slot": "background", "assetId": "asset-37d65d8f69" }] } }
```

- 运行时按槽位取图：`background` = 舞台背景，`music` = 循环 BGM，`dialogue-bg` = 对话背景。
- 素材本体按内容哈希存在项目目录里，工作台和播放页都通过带鉴权的 `GET /api/projects/:id/assets/:assetId` 取回。
- 导出时会把素材写进 `game/assets/` 并生成 `game/assets.json`，所以导出的独立游戏也有背景和音乐。
- 浏览器要求用户先点一下页面才允许放声音，所以 BGM 是“进游戏后点任意位置开始播”，不是 bug。

### 更多外观项

“积木搭建”模式顶部的 **外观与声音** 折叠面板还能直接改：背景色、地板色、墙色、强调色、文字色、格子大小、声音开关、卡牌布局（扇形手牌 / 桌面平铺）。

## 二、积木在哪里

工具栏中间的 **积木搭建** 按钮就是编辑模式（以前叫“编辑”，容易和别的东西混淆，所以改名）。游戏画面左上角的 **拼积木改规则** 也会切到这里。

进去以后有两层积木：

1. **组件积木**（编辑器最上面）
   按当前游戏类型给可拼接的组件。**从 P22 起支持拖拽吸附**：把积木（如“＋ 门”）直接拖到地图的某个地板格上松手即落位；地图里已有的对象也可以从对象列表拖到另一格移动位置。点击仍是快速添加（自动找空格），两种用法保留：键盘用户可 Tab 聚焦后回车添加。

   | 类型 | 可拼接 |
   |---|---|
   | 解谜 / 潜行 | ＋ 钥匙、＋ 门、＋ 守卫 |
   | 知识 | ＋ 单选题、＋ 配对题 |
   | 卡牌 | ＋ 攻击牌、＋ 敌人 |
   | 对话 | ＋ 旁白节点、＋ 结局 |

2. **规则积木**（编辑器下方，“规则积木（拖拽吸附）”区）
   左边是积木工具箱：蓝色**帽子块**（当…事件）、黄色**条件块**（如果…）、绿色**动作块**（那么…）。把积木拖进右边对应的吸附区：

   - 帽子块只能进“当”区；条件块只能进“如果”区；动作块只能进“那么”堆（可多个、可拖动换序）。
   - 拖回工具箱 = 拆下这块积木；拖错区域会出现红色提示并拒绝。
   - 参数直接在吸附后的块上改（下拉/输入框）。
   - 拼好后点 **放入配方** 提交为一条 GridRule；下方列表可对已有规则点 **编辑** 载入再拼。

   仍只生成 Schema 允许的组合：

   - 当：捡到道具 / 扳下开关 / 进入区域 / 任何行动后
   - 如果：背包里至少 N 个某类道具 / 历史上至少收过 N 个 / 某个标记为真
   - 那么：显示提示 / 设置标记 / 加分

   复杂的嵌套条件（`all` / `any` / `not`）和胜利目标还在同一块的“规则与胜利条件（结构化数据）”里直接编辑。

拼完点 **保存为新版本**，再点 **运行验证**；积木拼错了会被 verifier 拦下来，不会带病导出。

## 三、对话怎么往下写（去向在哪里设）

工作台 **积木搭建** → 对话编辑器里每一句是一张卡片，卡片底部的 **接下来** 决定这句之后去哪：

- **接到某一句**：在右边下拉框里选要接的那一句。
- **让玩家选择**：每个选项可以改文字、选“→ 跳到哪一句”、选“设置哪个标记”；点 **＋ 加一个选项** 会同时新建这个选项通向的一句。最多 4 个选项。
- **这里结束（进入结局判定）**：剧情在这句结束，按页面下方“结局”的顺序判定，第一个条件满足的结局生效。

续写最简单的方法：在想接着写的那句卡片右上角点 **在后面接一句**。新的一句会自动接在它后面，并继承它原来的去向（原来有选项就把选项挪到新句子上），光标直接落到新句子的台词框里。

其他：

- 卡片上的黄色提示“还没有任何一句通向这里 / 从开头走不到”说明这句玩家永远看不到，去某句的“接下来”里选它即可。
- **删除** 一句时，原来指向它的地方会改接到它的下一句，不会留下断链；开头那句不能删，可以先把别的句子 **设为开头**。
- 结局可改标题、文字和条件（无条件 / 需要某个标记为真），用 ↑↓ 调整判定顺序；无条件结局排在前面时会提示“后面的结局永远不会出现”。
- 需要新的分支条件时，在 **标记** 里点 ＋ 新标记，再在选项的“设置标记”和结局条件里选它。
- 改完点 **保存为新版本**，再 **运行验证**：会检查每句是否可达、每条路是否能走到结局、每个结局是否可达。

## 四、回收站

首页底部“回收站”现在是卡片列表：左侧游戏类型图标、中间名称/版本数/体积/删除时间、右侧 **还原** 与 **永久删除**。
“永久删除”需要点两次（第一次变成“确认永久删除”，旁边有取消），避免误删。
