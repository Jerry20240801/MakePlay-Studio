# 009 · 2026-11-16 · 对话续写去向可用性与结局末句丢失修复

## 用户反馈

「长夜渡轮自己往下写的句子没有地方设去向，不知道下一句去哪里。」

## 排查结论（两个原因）

1. 用户运行的是发行包里的旧版前端：积木编辑器（在后面接一句 / 接下来 / 去向 / 分支选项 / 结局编辑）已在源码里，但包内 bundle 是旧的。重新打包并核对了 src/pkg 的 app.js 哈希一致。
2. 真实产品缺陷：对话在终点节点（没有下一句的节点）进入瞬间内核就判定结局，播放器的结局面板只显示结局标题和文本，**作者写在最后节点的那句话玩家永远看不到**。E2E 逐帧 dump 证实（跳过本句后面板整体消失）。

## 修复

- packages/runtime/src/dialogue-game.tsx：结局/中断面板在结局标题前渲染最后节点的文本，testid dlg-final-line；与结局正文相同则不重复显示。
- 新增 tests/unit/dialogue-edit.test.ts：13 条针对积木编辑器去向操作的纯函数测试（接一句继承去向/分支点拆分/模式切换/选项增删回退/删除重连/孤立与不可达/结局排序与兜底截胡/标记占用）。
- 新增 tests/e2e/dialogue-editor.test.ts：真实浏览器完整链路——打开「末班车」→ 积木搭建 → 在后面接一句 → 写台词 → 校验去向选择器 → 保存新版本 → 试玩按打字机语义推进 → 断言结局面板显示新写句子 → 后端复跑验证 passed；产出截图两张（编辑器状态、玩家看到新句子的结局页）。

## 验证

unit 129 / integration 41 / security 8 / e2e 28 全部通过；发行包重建（74.1 MiB，sha256 78ef4212…），包内 bundle 与源码构建一致；test-dist 通过。

## 给用户的口径

- 续写：每句卡片上有「在后面接一句」（自动接上原去向）与「接下来：接到某一句 / 让玩家选择 / 这里结束」；去向只能从已有句子下拉选择，写不出死链。
- 一句「这里结束」的话，会在结局面板里作为最后一幕先显示出来，再显示结局标题与正文。
