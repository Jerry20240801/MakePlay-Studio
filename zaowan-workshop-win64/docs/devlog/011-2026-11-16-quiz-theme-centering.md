# 011 · 2026-11-16 · 知识闯关白块与居中修复（用户实测反馈）

## 现象

用户：「纯黑的背景有一片纯白，题目大卡片还不在正中央」。

## 根因

quiz-game.tsx 是运行时里唯一没接入"游戏画面固定深色主题"（--game-* 变量族，对话/卡牌/HUD 都用它）的组件：面板/选项/输入框/反馈文本全部硬编码浅色值（#ffffff 等），而游戏画面主题设计上不随应用主题切换，于是深色画面里出现纯白大卡片。配对题按钮只挂了类名，仓库里没有任何对应 CSS，等于完全裸奔。居中缺失：面板只有 margin: 0 auto（水平），纵向贴在盒顶。

## 修复

- styles 全部改 var(--game-*, 深色回退) 双层保险：宿主（工作台）有变量用变量；播放器/导出包没有变量时回退值同样是深色主题，不再依赖外部 CSS。
- 配对题左右按钮改挂内联 option() 样式（选中/已配对高亮），补上此前不存在的视觉状态。
- 根层新增 wrap（flex:1 + 居中），卡片在游戏盒内水平垂直都居中；HUD 占据的空间自然让出。
- 断言方式：浏览器真实渲染后用 getBoundingClientRect/getComputedStyle 判定（面板底色非白、水平中心偏差 ≤8px、盒内上下空隙差 ≤90px），截图前后对比存 docs/competition/evidence/quiz-theme-fix-2026-11-16/。

## 验证

- 修复后实测：panelBg=rgb(15,20,32)、optionBg=rgba(255,255,255,.05)、水平偏差 5px、垂直偏移 45px（为 HUD 让位，盒内居中）。
- quizshot 捕获/断言脚本保留在 tests/quizshot（SHOT_TAG 环境变量控制前/后）。
- 全量回归见下条命令记录；发行包与 submission/docker 重建。
