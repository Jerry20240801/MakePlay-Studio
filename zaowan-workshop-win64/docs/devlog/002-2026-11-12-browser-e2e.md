# 开发手记 002 · 2026-11-12 · 浏览器 E2E 打通

## 背景

第一轮结束时，浏览器 E2E 在本机被判定为「受阻」：Node 无法创建子进程，应用内启动的 Edge 因命名管道被拒绝而退出。复核时改用外部启动 Edge + CDP 连接（ZAOWAN_CDP_URL），浏览器侧可以工作了，E2E 真实运行后暴露出 7 个此前被「受阻」掩盖的产品缺陷，以及 1 个夹具错误。

## 缺陷与修复（按发现顺序）

### 1. CSP 阻止注入的会话令牌

- 现象：页面加载但 window.__ZAOWAN_TOKEN__ 为空，控制台报 inline script 违反 script-src。
- 原因：CSP 写死 script-src 只允许 self，注入令牌用的是内联脚本。
- 修复：每次响应生成 nonce，CSP 加 nonce，注入脚本带 nonce。

### 2. Origin 校验用了 0 端口

- 现象：/assets/app.js 返回 403，页面白屏。
- 原因：允许来源集合在 onReady 时用 server.address() 计算，此时尚未 listen，端口是 0。
- 修复：按请求 Host 头计算允许来源（127.0.0.1、localhost、[::1] 同端口），不再依赖启动时端口。

### 3. 浏览器包缺少 process.env.NODE_ENV

- 现象：页面报 process is not defined，React 无法启动。
- 原因：React 依赖构建期替换 NODE_ENV；Rollup 构建没有注入。
- 修复：构建浏览器包时用 @rollup/plugin-replace 注入 production；player 构建脚本同步。

### 4. 卡牌界面读取了知识状态

- 现象：卡牌样例报 Cannot read properties of undefined (reading 'length')，GamePlayer 崩溃。
- 原因：HUD 对知识与卡牌共用一段逻辑，卡牌状态下访问 state.answers.length。
- 修复：按模式包分别渲染 HUD（知识显示已答题数，卡牌显示回合与 RNG 计数）。

### 5. 导出的独立播放器忽略 bridge 参数

- 现象：导出包能打开，但测试桥始终未就绪，E2E 判定失败。
- 原因：导出包没有路由，bridge 只从 location.search 读取，而测试 URL 把参数放在 hash 中。
- 修复：同时解析 hash 查询串与 search；顺手给页面加 data: 图标消除 favicon 404 噪声。

### 6. 示例回放没有把候选版本写回工具上下文

- 现象：修复补丁创建了 v3，但后续 validate/复测仍指向 v2，复测必然失败。
- 原因：setCandidate 只更新 run.candidateVersionId，ToolContext.candidateVersionId 仍是 null。
- 修复：setCandidate 同时更新 ctx.candidateVersionId。

### 7. 浏览器试玩访问 127.0.0.1:0

- 现象：run_browser_playtest 报 ERR_UNSAFE_PORT。
- 原因：同 #2，服务器 baseUrl 在 onReady 时计算为端口 0。
- 修复：改用 onListen 钩子计算 baseUrl。

### 8. 回归夹具本身并不「坏」

- 现象：演示修复跑完却没有候选版本，测试断言 candidateVersionId 失败。
- 原因：第一版夹具的钥匙沿左侧走廊就能走到，静态检查本来就是通过的。
- 修复：重画地图，把钥匙放进只有门能进入的密室，BFS 变成 137 个状态耗尽；修复补丁把钥匙移到出生点旁后，BFS 找到 14 步路线。

## 结论

「环境受阻」不等于「产品正确」。外部 CDP 一接通，就暴露出 7 个真实缺陷和 1 个夹具错误；这也说明浏览器层的真实输入验证不可被内核测试替代。
