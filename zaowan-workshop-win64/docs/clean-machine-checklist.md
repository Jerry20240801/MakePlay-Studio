# 干净机器验证清单（提交前人工执行）

本机无法完成以下项目（没有第二台 Windows、不能新建用户账号、不能断网）。按顺序执行并把结果填回 docs/implementation-status.md；任何一项失败都要写清错误与截图，不要标为通过。

## 1. 无全局 Node 的新用户

1. 新建一个普通 Windows 用户账号（非管理员），或使用干净虚拟机。
2. 确认 PATH 中没有 node/npm/pnpm（cmd 里执行 where node 应失败）。
3. 解压 zaowan-workshop-win64.zip 到带中文和空格的目录，例如 C:\Users\<用户>\Desktop\造玩 工坊 测试\。
4. 双击 Start-Workshop.cmd：应打印启动地址并自动打开浏览器；关闭窗口后进程退出。

## 2. 安装目录只读

1. 把解压目录设为只读（右键属性只读，或放在 Program Files 下）。
2. 启动工作台：数据应写入 %LOCALAPPDATA%\ZaowanWorkshop，安装目录不应被写。
3. 若 %LOCALAPPDATA% 不可写，确认程序回退到临时目录/当前目录并给出日志。

## 3. 断网

1. 断开网络后启动：样例、手动编辑、验证（规则层）、导出应可用。
2. 点“真实模型”：应显示受阻/失败，不能整个应用崩溃。
3. 恢复网络后重试：应能重新连接（若已配置 key）。

## 4. 浏览器与导出

1. 不设置 ZAOWAN_CDP_URL，确认 Playwright 能启动本机 Chrome/Edge（launch 模式）；失败时记录提示。
2. 导出任意样例，解压到仓库外目录，双击 Start-Game.cmd，确认游戏能玩、无模型请求。
3. 对导出的对话包样例（末班车）确认 Enter/数字键可通关。

## 5. 新手任务（至少 3 人）

每人完成：一句话创建 → 改一条规则 → 看懂一次失败 → 采纳或自行修改 → 导出并在工作台外运行。记录耗时、求助次数、卡住位置、原话反馈；不要编造。
