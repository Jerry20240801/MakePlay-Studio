# 安全与隐私

## 模型密钥

- 本地发行版：只存在于后端会话内存，不持久化、不回显、不写入项目、日志或导出，重启即失。
- 公共实例（Docker 创空间，外部模式）：Key 持久化到该空间数据卷的 model-config.json（重启不丢，点"清除"即删除文件）；API 与页面只回显服务地址/模型名/是否已配置，绝不回显 Key 本身；警告横幅说明"清除前所有访客共用此 Key"。按实例所有者明确要求，公共实例不设填写限制。
- 后端只把 Key 作为认证头发送到用户确认的模型端点；拒绝跟随跨主机重定向，避免凭据被转发。
- 远程端点必须 HTTPS；HTTP 只允许 127.0.0.1 / localhost / ::1 的本地模型服务。

## 本地 API

- 只监听 127.0.0.1。
- 启动时生成随机会话令牌，注入首次页面；所有 /api 接口（除 /api/health）要求 Authorization 头。
- 校验 Host 与 Origin，拒绝跨站请求；不使用 CORS *。
- 页面设置 CSP，不开放远程脚本与 unsafe-eval。
- 模型输出、文件名、配方文本一律作为文本渲染，不写 innerHTML。

## 文件边界

- 项目 ID、版本 ID 只接受 [a-zA-Z0-9_-]{1,64}，防止路径穿越。
- 静态资源只从 apps/web/dist 或 apps/player/dist 解析，规范化后必须仍在目录内。
- 素材上传：只接受 PNG/JPEG/WebP，检查实际解码格式，限制 4 MiB 与 2048×2048，用 sharp 重新编码为 PNG 去除 EXIF，按内容哈希存储，展示名清洗为安全字符。
- 不执行模型提交的 shell、脚本或任意网络请求；补丁操作只有类型化白名单。

## 模型上下文最小化

发送：用户请求、支持的规则说明、相关配方摘要、已确认契约、必要工具结果。
不发送：API Key、环境变量、完整本机路径、未选目录文件、无关历史。

## 云端 AI 审查

- 只在用户选择“云端 AI 审查”或“本地 + 云端”时发起，每次最多 1 次模型请求；默认本地规则 0 调用。
- 发送内容：当前配方 JSON（最多约 12k 字符）、本地体检结论、已确认创作底线；不发送 API Key、环境变量、本机路径、无关文件或历史对话。
- 模型不获得工具；返回只按 summary/findings schema 解析，quickFix/ops/patch 字段被丢弃。云端结论永远不能直接修改配方。
- 审查证据写入 runs/review-*/review.json 与 model-usage.json：只含模式、模型名、请求/ token、findings；不含 Key。
- 失败/跳过语义：MODEL_AUTH_FAILED、超时、非 JSON 都记录为 failed 并显示原因；界面同时回退展示本地体检结论，不能把失败说成通过。
- 成本提示：UI 在选项旁标注“1 次模型调用”，审查状态显示实际请求数与 token；未连接模型时云端选项禁用。

## 已知限制

- 「清除引用」不等于可证明的内存擦除。
- 项目导入接口尚未实现，因此 ZIP Slip / 压缩炸弹防护只做了通用目录边界检查，没有可测试的导入路径。
- 断网时模型调用会显示受阻，其余功能（编辑、样例、手动试玩、导出）应继续可用；本机未做断网实测。

## 公共实例（魔搭创空间）的 Origin 策略（2026-11-16）

创空间实际访问域为 *.ms.show，平台网关把 Host 重写为 *.fcapp.run，且 module script 请求必带 Origin：
若沿用本地"同主机名才放行"的严格校验，前端资源会被自己拦死（本次白屏的直接原因）。

外部模式改为：modelscope.cn / ms.show / fcapp.run 域族放行；其他 Origin 仅记录（SOFT-ORIGIN），不拦截。
防 CSRF 的实际防线不变：写操作必须携带随机会话令牌（X-Zaowan-Session / Authorization 二选一），
第三方页面无法读取该令牌；CSP 同时限制可嵌入域。本地发行版保持对任何非回环 Host 与陌生 Origin 的硬拒绝。
