## 云端审查的边界

- e2e 使用本地替身模型（1 次“模型调用”的桩）验证三档链路、证据落盘与密钥不外泄；不是真实云端模型能力证据。
- 2026-11-14 用 ModelScope 端点尝试一次真实云端审查，返回 **MODEL_AUTH_FAILED**（1 次请求、无 findings），因此“真实云端模型审查”仍标记为待补，未用替身冒充。
- 云端失败时 UI 显示失败原因，并回退展示本地体检结论；不会把失败说成通过。
